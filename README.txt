QUANTREX SOLUTIONS WEBSITE
===========================

Files:
- index.html  -> complete single-page website
- style.css   -> responsive styling, animations, loading screen and visual effects
- script.js   -> mobile menu, scroll reveal, pricing order modal and WhatsApp checkout
- assets/quantrex-logo.jpg -> logo reference extracted from the supplied poster

NOTES
-----
1. The founder image currently uses the public image URL from Kiaan Bhatta's website:
   https://www.kiaanbhatta.com.np/images/kiaan.jpg
   You can replace that <img> src with a local file if preferred.
2. Website orders are sent to WhatsApp number +977 9848460294 through wa.me.
3. The site is framework-free: HTML + CSS + vanilla JavaScript only.
4. No server/database is required for the current WhatsApp order flow.

HOW TO RUN
-----------
Open index.html in a browser, or deploy the folder to Vercel/Netlify/GitHub Pages.
